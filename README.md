# Chapio Trading Academy v0.3.0

無料で配布できる教育用ブラウザゲーム。11コース、45問、基礎修了によるコース解放、復習、学習記録のローカル保存、架空OHLCチャート演習に対応します。

## 遊び方
ZIPを解凍し、`index.html` を開きます。オフライン版の教材は同梱されています。

## 中央更新
オンライン版を **GitHub Pagesなど同一URL** で配布すると、`content.json` を更新するだけで全利用者が次回アクセス時に新しい教材を取得します。ゲーム本体の更新はページ再読み込みが必要です。公開方法は `DEPLOY_GUIDE.md` を参照。

## 今回の変更
- 模擬チャート描画の縦軸に未来のローソク足を使ってしまう先読みを修正。
- チャート演習を毎回異なる架空の値動きに変更。
- 回答の二重確定防止。
- GitHub Pagesデプロイ用GitHub Actionsの雛形を同梱。

## 制約
- 実市場OHLC、クラウド同期、AI問題生成、完全な適応型難易度、実機横断テストは未実装。
- 問題数は45。専門コースはまだ少数の導入問題のみ。
- ZIP配布版は自動更新不可。Web公開版でも接続中の画面が自動で書き換わるわけではありません。
- 学習記録はブラウザ単位のlocalStorage。バックアップはエクスポート機能を使用。
